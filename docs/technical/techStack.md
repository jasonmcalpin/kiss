# Tech Stack

## Frontend
- **Language**: TypeScript - Provides type safety and better development experience while maintaining JavaScript compatibility
- **Framework**: Vanilla TypeScript with modern DOM APIs - No heavy frameworks to keep the codebase simple and educational
- **Styling**: Custom CSS with dark infographic aesthetic - Clean, professional dashboard-like appearance
- **Build Process**: TypeScript compiler with modern ES modules
- **Real-time**: WebSockets for multiplayer game updates and chat

## Backend and API
- **Database**: MySQL since my host has MySQL services i can use at no additional cost and allow people to reach it from anywhere.
- **API**: Python. with the host able to run python I will use FastAPI to create a RESTful API for the game. This is a modern system that I already have some game code written for the universe generation, name generation and alien races which I can expand from the Traveller RPG character generator I expanded.  
- **User Authentication**: FastAPI with JWT for secure user authentication and session management.

## Development Tools
- **Type Checking**: TypeScript compiler for compile-time error detection
- **Testing**: Jest for unit and integration testing
- **Code Quality**: ESLint for code consistency and best practices
- **Containerization**: Docker for consistent development and deployment environments
